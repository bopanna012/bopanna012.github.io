# Portfolio

Personal portfolio website for Yashu Bopanna Pasura Devaiah, a cloud engineer — built with vanilla HTML, CSS, and JavaScript.

## Sections

- Hero introduction with resume download
- About
- Projects
- Skills
- Experience
- Education
- Certifications
- Testimonials
- Blog
- Contact

## Running locally

This is a static site with no build step. Open `index.html` directly in a browser, or serve it locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

```
index.html   Page markup
style.css    Styling
script.js    Nav toggle, scroll-reveal animations, active nav highlighting, back-to-top
```
